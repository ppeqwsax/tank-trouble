# 坦克动荡 · Tank Trouble

一个纯前端、零依赖的经典坦克对战小游戏：炮弹撞墙反弹、一炮定生死。支持**单人对战电脑**（三档难度）与**双人同屏对战**。

在线试玩：<https://ppeqwsax.github.io/tank-trouble/>

## 玩法规则

- **每局随机生成地图**：一张 180° 旋转对称的迷宫（出生点周围留空、全图连通），保证双方地形完全对等；同一局内所有回合共用同一张图。也可以在菜单里切换回「经典地图」。
- 坦克只能前后行驶与原地转向，没有刹车以外的横向位移。
- 炮弹撞墙会**反弹**，单发最多反弹 **5** 次。
- **一击即毁**：被任何炮弹命中即出局。
- 炮弹在反弹至少一次后，也会伤到开炮者自己 —— **误伤同样算对手得分**。
- 先赢 **5** 回合者获得整场胜利。
- 场景中会随机刷新道具：
  - 🛡 **盾**：抵挡一次伤害
  - ⚡ **连**：射速翻倍
  - 💨 **速**：移动速度提升
  - 🎯 **三**：一次射出三发扇形炮弹

## 操作

| 操作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 前进 / 后退 | `W` / `S` | `↑` / `↓` |
| 左转 / 右转 | `A` / `D` | `←` / `→` |
| 开火 | `F` | `空格` |

全局快捷键：`P` 或 `Esc` 暂停，`M` 静音。

## 本地运行

无需构建、无依赖，直接双击 `index.html` 即可；也可以起任意静态服务器：

```bash
npx serve .
```

## 目录结构

```
index.html        页面骨架与 HUD
css/style.css     深色霓虹风样式
js/core.js        常量、工具函数、墙体碰撞、音效
js/entities.js    坦克 / 炮弹 / 道具实体
js/ai.js          电脑 AI（简单 / 普通 / 困难）
js/game.js        回合与整场状态机、渲染
js/main.js        输入、菜单、主循环
```

## 部署

仓库使用 GitHub Pages 直接从 `main` 分支根目录发布，无需任何 CI。
