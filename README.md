# 坦克动荡 · Tank Trouble

一个纯前端、零依赖的经典坦克对战小游戏：炮弹撞墙反弹、一炮定生死。支持**单人对战电脑**（三档难度）、**双人同屏对战**，以及**联机 1v1**（6 位房间码）。

在线试玩：<https://ppeqwsax.github.io/tank-trouble/>

## 玩法规则

- **每局随机生成地图**：一张 180° 旋转对称的迷宫（出生点周围留空、全图连通），保证双方地形完全对等；同一局内所有回合共用同一张图。也可以在菜单里切换回「经典地图」。
- 坦克只能前后行驶与原地转向，没有刹车以外的横向位移。
- 炮弹撞墙会**反弹**，单发最多反弹 **5** 次。
- **一击即毁**：被任何炮弹命中即出局。
- 炮弹在反弹至少一次后，也会伤到开炮者自己 —— **误伤同样算对手得分**。
- 先赢 **5** 回合者获得整场胜利。
- 场景中会随机刷新道具：
  - 🛡 **盾**：抵挡一次伤害
  - ⚡ **连**：射速翻倍
  - 💨 **速**：移动速度提升
  - 🎯 **三**：一次射出三发扇形炮弹

## 操作

| 操作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 前进 / 后退 | `W` / `S` | `↑` / `↓` |
| 左转 / 右转 | `A` / `D` | `←` / `→` |
| 开火 | `F` | `空格` |

全局快捷键：`P` 或 `Esc` 暂停，`M` 静音。联机模式下每人一台电脑，两套按键都能用。

## 暂停与退出

游戏中随时可以停下来：

- 点右上角 **「暂停」** 按钮，或按 `P` / `Esc`；
- 暂停面板里可以直接 **继续游戏**、**重新开始**，或 **退出到主菜单**；
- 切到别的标签页 / 最小化窗口时会自动暂停，回到游戏不会白挨一发。

暂停会冻结画面与 AI，不会计入任何时间。联机对局里暂停权在房主手上，客机按 `P` 只会提示一句「联机中由房主暂停」。

## 联机对战（1v1）

菜单选「联机对战」：

1. 一方点 **创建房间**，得到 6 位房间码（也可以点「复制邀请链接」）；
2. 另一方点 **加入房间**，输入房间码，或直接打开邀请链接；
3. 对手进房间后自动开局，房主在蓝方、客机在红方，地图由房主生成后下发。

实现要点：

- **房主权威**：房主跑完整物理模拟，以 18Hz 下发快照；客机上传按键、按 110ms 缓冲插值还原对手与炮弹，**自己那辆坦克做本地预测**，所以按键到画面没有往返延迟。
- 传输用 Supabase Realtime 的匿名广播通道（`js/netplay.js` 手写 Phoenix 协议，不引入 supabase-js），房间码就是频道名，不需要自建服务器。
- `js/net-config.js` 里的 `anon` key 是**公开键**，浏览器端使用没有风险；`service_role` 密钥不在这里。
- 客机掉线 7 秒后房主会看到「连接中断」，房主掉线客机同样会提示；结算与「再来一局」也会同步。

> 房间码是公开频道，抢到房间码的人理论上能旁观广播（只能用房间码猜到），仅用于朋友间对局。

## 本地运行

无需构建、无依赖，直接双击 `index.html` 即可；也可以起任意静态服务器：

```bash
npx serve .
```

## 目录结构

```
index.html        页面骨架与 HUD
css/style.css     深色霓虹风样式
js/core.js        常量、工具函数、墙体碰撞、音效
js/entities.js    坦克 / 炮弹 / 道具实体
js/ai.js          电脑 AI（简单 / 普通 / 困难）
js/game.js        回合与整场状态机、渲染
js/net-config.js  联机配置（Supabase 项目地址 + 公开 anon key）
js/net.js         Realtime 通道客户端（手写 Phoenix 协议）
js/netplay.js     联机对战：房间码、快照广播、插值与本地预测
js/main.js        输入、菜单、主循环
```

## 部署

仓库使用 GitHub Pages 直接从 `main` 分支根目录发布，无需任何 CI。
